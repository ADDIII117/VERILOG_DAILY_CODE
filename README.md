# VERILOG_DAILY_CODE

A daily Verilog practice repository focused on building a strong foundation in digital design, VLSI concepts, and hardware verification.

This project covers both combinational and sequential logic circuits, with implementations and testbenches designed to improve practical understanding of HDL-based digital design.

## About the Repository

This repository is intended for learning and improving skills in:
- Verilog HDL design
- Digital logic implementation
- Sequential circuit design
- Testbench creation and simulation
- ASIC/FPGA design flow fundamentals

## Tools and Technologies

- Verilog HDL
- Xilinx Vivado
- ModelSim / QuestaSim
- Cadence Virtuoso (for VLSI-focused workflows)

## Learning Goals

The main goal of this repository is to help build industry-ready skills in digital design and VLSI by practicing daily logic problems and validating them through simulation.

## Repository Structure

The project includes daily exercises such as:
- Logic Gates
- Half Adder / Full Adder
- Flip-Flops and Latches
- Counters and Sequential Logic
- Combinational and Sequential Design Practice
- Simulation and waveform verification

Each folder typically contains:
- HDL source files (`.v`)
- Testbench files (`*_tb.v`)
- README documentation for the exercise

## Typical Workflow

For each daily problem:
1. Understand the digital logic requirement
2. Write the Verilog module
3. Create a testbench to stimulate the design
4. Simulate the behavior
5. Validate the results using waveforms and output checks

## Why This Repository?

This repository is useful for:
- Students learning digital electronics and Verilog
- Beginners building practical HDL skills
- Hardware enthusiasts exploring sequential logic design
- Engineers preparing for VLSI and digital design interviews

## Project Focus

The repository emphasizes:

`VERILOG_DAILY_CODE` is a hands-on learning repository designed to strengthen understanding of digital logic and Verilog implementation through daily coding challenges and simulation-based validation.
